## 🎯 Objetivo do Projeto

A proposta foi transformar um conjunto de dados brutos em uma aplicação visual e intuitiva. O dashboard permite analisar salários por:

* **Ano** e **Senioridade**
* **Tipo de contrato** e **Tamanho da empresa**
* **Localização** (País)
* **Modelo de trabalho** (Remoto, Híbrido, Presencial)

## 📌 Funcionalidades Implementadas

### 🔎 Filtros Interativos (Sidebar)
O usuário tem controle total sobre os dados, podendo filtrar dinamicamente por:
1. Ano de referência
2. Nível de senioridade
3. Tipo de contrato e tamanho da empresa

### 📈 Métricas Principais (KPIs)
Cards visuais que mostram instantaneamente:
* 💰 **Salário médio anual (USD)**
* 🏆 **Salário máximo**
* 📊 **Total de registros**
* 👔 **Cargo mais frequente**

### 🌍 Visualizações Destacadas
* **Top 10 Cargos:** Ranking por média salarial.
* **Distribuição:** Histograma de concentração de renda.
* **Mapa Coroplético:** Visualização geográfica da média salarial para *Data Scientists*.
